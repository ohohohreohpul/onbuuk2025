---
title: Hilfe von einem Menschen
description: Schreiben Sie dem Zenno-Team an support@zennohq.com.
sidebar:
  order: 1
---

Tippen Sie in der App unten im Menü auf **Hilfe** und dann auf **E-Mail schreiben**. Ihr E-Mail-Programm öffnet sich, und Ihre Kontodaten sind schon eingetragen. So können wir Ihnen schneller helfen.

Oder schreiben Sie direkt an **support@zennohq.com**.

Bitte schreiben Sie uns:

1. Was Sie tun wollten.
2. Was stattdessen passiert ist.
3. Einen Screenshot, wenn möglich.

Ein Mensch aus dem Zenno-Team antwortet Ihnen.
