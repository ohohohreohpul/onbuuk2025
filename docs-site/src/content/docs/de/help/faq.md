### Ein Gast findet online keine freie Zeit.
Freie Zeiten ergeben sich aus den **Arbeitszeiten** der Therapeut:innen, abzüglich Buchungen, blockierter Zeit und Schließtagen. Prüfen Sie [Therapeut:innen](/de/settings/specialists/).

### Gäste bekommen keine E-Mails.
Richten Sie unter **Einstellungen → E-Mails** einen Absender ein und tippen Sie auf **Test-E-Mail senden**. Siehe [E-Mails](/de/settings/emails/).

### Die KI hat auf meinen WhatsApp-Test nicht geantwortet.
Nachrichten vom Handy des Ladens werden absichtlich nicht beachtet. Beginnen Sie Ihren Test mit `#test`. Siehe [Auf WhatsApp testen](/de/ai-receptionist/test/).

### Kann die KI falsche Preise nennen?
Sie nutzt nur Preise aus Ihrer App. Steht etwas nicht in der App, gibt sie den Chat an Sie ab.

### Jemand in meinem Team soll keine Zahlen zum Geld sehen.
Geben Sie der Person die Rolle **Mitarbeiter:in** oder **Empfang**. Siehe [Team und Berechtigungen](/de/settings/team/).

### Ich brauche Hilfe von einem Menschen.
Schreiben Sie an **support@zennohq.com**. Siehe [Hilfe von einem Menschen](/de/help/get-help/).
