Tippen Sie im Kalender auf eine Buchung. Die Buchung öffnet sich mit drei einfachen Schritten und den Angaben des Gastes. Tippen Sie auf die Telefonnummer, um den Gast anzurufen.

## 1 · Bestätigung

Wartet die Buchung auf Sie (gelbe Karte, „Bitte bestätigen“), tippen Sie auf **Buchung bestätigen** oder **Ablehnen**. Wenn Sie ablehnen, bekommt der Gast eine E-Mail.

## 2 · Ist die Kundin / der Kunde gekommen?

Tippen Sie am Tag des Termins auf **Ja, gekommen** oder **Nein, nicht gekommen**. Ein No-Show wird im Kalender blass. Wenn Sie No-Show-Gebühren verlangen, nennt Zenno Ihnen die Gebühr. Siehe [No-Show-Gebühren](/de/money/no-show-fees/).

## 3 · Zahlung

Ist der Gast gekommen, tippen Sie an, wie er bezahlt hat: **Bar**, **Karte**, **Gutschein** (Code eingeben und auf **Einlösen** tippen) oder **Anders / geteilt…** für mehrere Zahlungen. Auf der Karte erscheint ein grüner Haken. Etwas falsch eingegeben? Tippen Sie auf **Rückgängig**.

## Weitere Aktionen

Unter **Weitere Aktionen** finden Sie:

- **Termin verschieben**: Wählen Sie ein neues Datum und unter **Freie Zeiten** eine neue Uhrzeit. Der Gast bekommt eine E-Mail mit der neuen Uhrzeit und eine neue Erinnerung.
- **No-Show-Gebühr anlegen** oder **Gebühr klären**.
- **Rechnung (PDF)**.
- **Als bestätigt wiederherstellen**, wenn Sie eine Buchung aus Versehen abgeschlossen haben.
- **Buchung absagen**: Der Gast bekommt eine E-Mail, und die Zeit ist wieder frei.

## Notiz fürs Team

Schreiben Sie eine **Notiz fürs Team**, zum Beispiel „möchte zu Nann, kräftiger Druck, Rücken/Nacken“, und tippen Sie auf **Notiz speichern**. Nur Ihr Team sieht sie, nie der Gast. Die Notiz steht auch auf der Karte im Kalender.
