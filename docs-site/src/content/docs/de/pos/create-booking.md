---
title: Termin eintragen
description: Einen Termin für einen Gast eintragen, der anruft oder vorbeikommt.
sidebar:
  order: 2
---

1. Tippen Sie in **POS** auf die freie Zeit, an der der Termin beginnen soll. In der Tagesansicht tippen Sie in die Spalte der Therapeut:in.
2. Wählen Sie **Termin eintragen**. Das Fenster **Termin eintragen** öffnet sich.
3. Wählen Sie die **Behandlung** und die **Dauer**. Neben jeder Dauer steht der Preis.
4. Prüfen Sie **Therapeut:in** sowie **Tag und Uhrzeit**. Zenno zeigt unter **Freie Zeiten**, was noch frei ist. Tippen Sie eine Zeit an.
5. Suchen Sie unter **Kundin / Kunde** nach Name, Telefon oder E-Mail. Ist der Gast neu? Tippen Sie auf **Neue Kundin / neuer Kunde** und tragen Sie **Name**, **Telefon** und, falls vorhanden, **E-Mail** ein. An diese Adresse geht die Bestätigung.
6. Schreiben Sie bei Bedarf eine **Notiz fürs Team**, zum Beispiel „kräftiger Druck, Allergien“. Nur Ihr Team sieht sie.
7. Tippen Sie auf **Termin eintragen**.

Der Termin erscheint sofort im Kalender.

:::note[Suche nach Telefonnummer]
Sie können die Telefonnummer so eingeben, wie Sie möchten: mit Leerzeichen, mit +49 oder mit 0. Zenno findet den Gast über die letzten Ziffern.
:::

:::tip[Ein Anrufer möchte es sich noch überlegen]
Halten Sie die Zeit frei, ohne einen Termin anzulegen: [Blockieren Sie die Zeit](/de/pos/block-time/) mit einem Kommentar. Später machen Sie mit einem Tipp einen richtigen Termin daraus.
:::
