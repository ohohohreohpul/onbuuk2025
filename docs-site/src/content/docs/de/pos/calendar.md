**POS** ist der erste Punkt im Menü. Dort öffnet sich der Kalender. Darunter stehen die Zahlen des Tages, wenn Sie Berichte sehen dürfen. Die meiste Zeit des Tages brauchen Sie nur diese Seite.

## Tag, Woche, Monat

Oben wechseln Sie zwischen **Tag**, **Woche** und **Monat**. Mit den Pfeilen blättern Sie vor und zurück. Mit **Heute** kommen Sie zum heutigen Tag zurück.

- **Tag** zeigt eine Spalte pro Therapeut:in. Das ist die beste Ansicht an der Theke.
- **Woche** zeigt die ganze Woche, alle Therapeut:innen zusammen.
- **Monat** gibt Ihnen einen Überblick. Tippen Sie auf einen Tag, um ihn zu öffnen.

## Was die Farben bedeuten

Jede Therapeut:in hat eine eigene Farbe. Auf einer Buchungskarte sehen Sie einen kleinen farbigen Punkt, die Uhrzeit, den Namen des Gastes und die Behandlung.

| Sie sehen | Das bedeutet |
| --- | --- |
| Karte in der Farbe einer Therapeut:in | Eine bestätigte Buchung |
| Gelbe Karte mit gestricheltem Rand, „Bitte bestätigen“ | Die Buchung wartet auf Ihre Bestätigung |
| Kleiner grüner Haken | Die Buchung ist bezahlt |
| Blasser, durchgestrichener Name, „Nicht gekommen“ | Der Gast ist nicht gekommen (No-Show) |
| Gestreiftes Feld | Blockierte Zeit, mit Kommentar |
| Rote Linie | Die aktuelle Uhrzeit |

## Etwas erledigen

- **Tippen Sie auf eine freie Zeit.** Ein kleines Fenster fragt *Was möchten Sie tun?*: **Termin eintragen** oder **Zeit blockieren**. Wenn Sie die Maus über den Kalender bewegen, zeigt ein kleines „+ 14:30“, wo der Termin beginnen würde.
- **Tippen Sie auf eine Buchung**, um sie zu bestätigen, einzutragen, ob der Gast gekommen ist, die Zahlung zu erfassen, sie zu verschieben oder abzusagen, oder eine Notiz fürs Team zu schreiben.
- **Tippen Sie auf eine blockierte Zeit**, um sie zu ändern, zu entfernen oder einen richtigen Termin daraus zu machen.
- Die Knöpfe **Gutschein verkaufen** und **Gutschein einlösen** finden Sie oben im Kalender.
- Mit **Therapeut:innen anzeigen** wählen Sie, wessen Spalten Sie sehen.

:::tip
Lassen Sie den Kalender auf dem Tablet an der Theke auf **Tag** stehen. Dann ist alles nur einen Tipp entfernt.
:::
