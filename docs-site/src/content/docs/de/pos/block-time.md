Blockieren Sie Zeit für eine Pause, für Urlaub oder einen Arzttermin. Oder wenn eine Therapeutin früher gehen muss. Oder wenn Sie eine Zeit für jemanden am Telefon freihalten möchten. Blockierte Zeit können Gäste nicht online buchen, und die KI-Rezeption bietet sie nicht an.

## Zeit blockieren

1. Tippen Sie in **POS** auf die Uhrzeit, an der die Blockierung beginnen soll, und wählen Sie **Zeit blockieren**. Sie können auch oben auf den Knopf **Zeit blockieren** tippen.
2. **Wer?** Wählen Sie die Therapeut:in, oder **Ganzer Laden**, wenn der Laden geschlossen ist.
3. Stellen Sie **Datum**, **Von** und **Bis** ein, oder haken Sie **Ganzer Tag** an.
4. Wählen Sie einen **Grund**: Pause, Urlaub, Krank, Privater Termin oder Geschlossen.
5. Schreiben Sie einen **Kommentar**, wenn es hilft. Zum Beispiel: *Fr. Weber · Rücken/Nacken · 0151 2345 6789*.
6. Wählen Sie eine **Farbe**, damit Sie die Zeit sofort erkennen. Zum Beispiel Grün für Reservierungen am Telefon.
7. Gilt dieselbe Zeit an mehreren Tagen, haken Sie **Mehrere Tage** an und wählen Sie unter **Letzter Tag** den letzten Tag.
8. Tippen Sie auf **Speichern**.

Die Zeit erscheint als gestreiftes Feld in Ihrer Farbe. Der Kommentar steht darin.

## Aus einer blockierten Zeit einen Termin machen

Wenn der Anrufer zusagt:

1. Tippen Sie auf die blockierte Zeit.
2. Tippen Sie auf **Als richtigen Termin eintragen**.
3. Das Fenster **Termin eintragen** öffnet sich. Uhrzeit, Therapeut:in und die Telefonnummer aus Ihrem Kommentar sind schon eingetragen. Prüfen Sie alles und tippen Sie auf **Termin eintragen**.

Die blockierte Zeit wird erst entfernt, wenn der Termin gespeichert ist. So geht Ihnen die Zeit nie verloren.

## Ändern oder entfernen

Tippen Sie auf die blockierte Zeit. Ändern Sie, was nötig ist, und tippen Sie auf **Speichern**. Oder tippen Sie auf **Blockierung entfernen** und dann auf **Ja, entfernen**.
