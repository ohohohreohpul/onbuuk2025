---
title: Gutschein einlösen
description: Ein Gast bezahlt mit einem Gutschein. Code prüfen und Betrag abziehen.
sidebar:
  order: 2
---

**Wenn der Gast eine Buchung bezahlt:** Öffnen Sie die Buchung, gehen Sie zu **3 · Zahlung**, tippen Sie auf **Gutschein**, geben Sie den Code ein und tippen Sie auf **Einlösen**.

**Ohne Buchung:** Tippen Sie in **POS** auf **Gutschein einlösen**.

1. Scannen Sie den **QR-Code** auf dem Gutschein mit der Kamera, oder tippen Sie den **Code** ein.
2. Zenno zeigt den Restwert. Bei einer Mehrfachkarte zeigt Zenno die übrigen Besuche.
3. Geben Sie den Betrag ein, der abgezogen werden soll, und bestätigen Sie.

Der Rest bleibt für den nächsten Besuch auf dem Gutschein.
