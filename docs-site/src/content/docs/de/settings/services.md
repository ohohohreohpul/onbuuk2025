## Eine Behandlung anlegen

1. Öffnen Sie **Leistungen** → **Leistung hinzufügen**.
2. Tragen Sie **Name der Leistung**, **Beschreibung** und **Kategorie** ein. Gibt es die Kategorie noch nicht, tippen Sie auf **+ Neue Kategorie anlegen**.
3. Tippen Sie unter **Dauer & Preise** für jede Länge auf **Dauer hinzufügen**, zum Beispiel 60 Min. · 70 € und 90 Min. · 95 €.
4. Wenn Sie möchten:
   - **Als Paarbuchung buchbar**: Gäste können die Behandlung zu zweit buchen.
   - **Auf der Buchungsseite ausblenden**: Im Kalender können Sie die Behandlung weiter eintragen, und Gutscheine bleiben gültig.
   - **Puffer davor (Minuten)** und **Puffer danach (Minuten)**: Zeit zum Vorbereiten oder Aufräumen.
   - **No-Show-Gebühr**, **Gebühr für späte Stornierung**, **Stornierung bis (Stunden vorher)**.
5. Tippen Sie auf **Leistung anlegen**.

Viele Behandlungen auf einmal? Tippen Sie auf **Importieren**, laden Sie die Vorlage herunter, füllen Sie sie aus und laden Sie sie wieder hoch.

## Zusatzprodukte

Unter **Zusatzprodukte** → **Produkt hinzufügen** bieten Sie Extras an, die Gäste zu einer Buchung dazunehmen können. Zum Beispiel heiße Steine oder ein Aromaöl: Name, Preis, Bild und für welche Behandlungen es das Extra gibt.
