Gäste können nur buchen, wenn eine Therapeut:in arbeitet. Die Arbeitszeiten bestimmen also Ihre freien Zeiten.

## Eine Therapeut:in anlegen

1. Öffnen Sie **Therapeut:innen** → **Therapeut:in hinzufügen**.
2. Tragen Sie unter **Vollständiger Name** den Namen ein. Wenn Sie möchten, schreiben Sie unter **Kurzprofil** ein paar Sätze und fügen ein Bild hinzu.
3. Haken Sie unter **Angebotene Leistungen** die passenden Behandlungen an.
4. Lassen Sie **Aktiv (für Buchungen verfügbar)** eingeschaltet und tippen Sie auf **Therapeut:in anlegen**.

## Arbeitszeiten

Tippen Sie auf der Karte der Therapeut:in auf **Arbeitszeiten**. Stellen Sie für jeden Tag Beginn und Ende ein (freie Tage haken Sie ab) und tippen Sie auf **Arbeitszeiten speichern**.

## Freie Tage

Tippen Sie auf **Zeitblöcke** für Urlaub oder Krankheitstage: Beginn, Ende und Grund. Für eine kurze Pause heute [blockieren Sie lieber Zeit](/de/pos/block-time/) im Kalender.

## Schließtage des Ladens

Tippen Sie auf **Schließtage** → **Schließtage hinzufügen**, für Feiertage oder Ihren eigenen Urlaub. An diesen Tagen kann niemand buchen, weder online noch über die KI. Bestehende Buchungen bleiben erhalten.

## Dürfen Gäste ihre Therapeut:in wählen?

Der Schalter **Kunden wählen ihre Therapeut:in** ist auf dieser Seite. Ist er aus, überspringt die Buchungsseite diesen Schritt und gibt die Buchung an eine freie Therapeut:in. Die KI-Rezeption nennt dann auch keine Namen.
