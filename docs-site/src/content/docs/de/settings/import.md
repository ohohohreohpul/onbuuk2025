---
title: Von einem anderen Programm umziehen
description: Kund:innen, Termine und blockierte Zeiten aus EasyWeek, Shore, Treatwell und anderen übernehmen.
sidebar:
  order: 6
---

1. Exportieren Sie Ihre Daten aus Ihrem alten Programm als CSV-Dateien.
2. Gehen Sie in Zenno zu **Einstellungen → Import** → **Aus einem anderen System importieren**.
3. Wählen Sie, was Sie übernehmen möchten: **Kunden**, **Termine** oder **Blockzeiten**. Laden Sie dann die Datei hoch.
4. Prüfen Sie die Vorschau und starten Sie den Import.

Übernommene Termine verschicken keine Bestätigungs-E-Mails. Die Erinnerung am Vortag bekommen die Gäste aber trotzdem.

Behandlungen übernehmen Sie unter **Leistungen** → **Importieren**, Gutscheine unter **Gutscheine → Gutscheine** → **CSV importieren**.
