Öffnen Sie im Menü **KI-Rezeption**.

## 1. Der Hauptschalter

Oben rechts sehen Sie den Status: **An – die Rezeption antwortet** oder **Aus – niemand bekommt automatisch Antwort**. Tippen Sie auf den Schalter, um die Rezeption für alle Kanäle gleichzeitig ein- oder auszuschalten.

## 2. Kanäle verbinden

Öffnen Sie den Reiter **Kanäle**. Wählen Sie oben, wie es für alle Kanäle laufen soll: **Automatisch antworten** oder **Nur Entwürfe**.

### Website-Chat

1. Schalten Sie **Website-Chat** ein.
2. Kopieren Sie die Zeile unter **Code für Ihre Website**. Fügen Sie sie in Ihre Website ein, direkt vor `</body>`. Oder schicken Sie sie an die Person, die Ihre Website betreut.
3. Auf Ihrer Website erscheint eine Chat-Blase, in Ihrer Farbe und mit Ihrem Begrüßungstext.

### E-Mail

Die Rezeption liest neue E-Mails in Ihrem eigenen Postfach und antwortet von dort.

1. Richten Sie zuerst Ihr Postfach unter **Einstellungen → E-Mails** ein (siehe [E-Mails](/de/settings/emails/)).
2. Schalten Sie unter **Kanäle** die **E-Mail** ein und tragen Sie **IMAP-Server** und **Port** Ihres Postfachs ein. **Benutzername** und **Passwort** können leer bleiben, wenn sie dieselben sind wie beim Senden.
3. Tippen Sie auf **Testen und verbinden**. Steht dort **Verbunden**, werden neue E-Mails beantwortet.

### WhatsApp

1. Schalten Sie **WhatsApp** ein und wählen Sie **Eigene Nummer (QR scannen)**. Größere Läden können stattdessen **Offizielles WhatsApp Business** nutzen.
2. Tippen Sie auf **Verbinden**. Ein QR-Code erscheint.
3. Öffnen Sie auf dem Handy des Ladens WhatsApp → **Verknüpfte Geräte** → **Gerät verknüpfen** und scannen Sie den Code.
4. Steht dort **Verbunden** mit Ihrer Nummer, bekommen Gäste, die Ihnen schreiben, eine Antwort.

Ihr Handy funktioniert ganz normal weiter. Nachrichten, die Sie selbst vom Handy schicken, beantwortet die KI nie.

## 3. Testen

- **Website:** Tippen Sie unter **Persönlichkeit** auf **Im Chat ausprobieren**.
- **WhatsApp ohne zweites Handy:** siehe [Auf WhatsApp testen](/de/ai-receptionist/test/).
