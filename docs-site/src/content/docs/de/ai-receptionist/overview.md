Die KI-Rezeption antwortet Ihren Gästen, Tag und Nacht, in ihrer Sprache. Sie:

- beantwortet Fragen zu Behandlungen, Preisen, Öffnungszeiten und Gutscheinen,
- sucht **wirklich freie Zeiten** in Ihrem Kalender und bucht den Termin,
- findet, verschiebt oder storniert die Buchung eines Gastes (nur für die eigene, geprüfte Nummer oder E-Mail des Gastes),
- gibt den Chat an Sie ab, wenn sie unsicher ist, wenn sich jemand beschwert, nach Erstattungen oder Gesundheit fragt oder verärgert ist.

Alles, was sie über Preise, Zeiten und Angebote sagt, kommt aus Ihrer App. Steht etwas nicht in der App, rät sie nicht. Sie gibt dann an Sie ab.

## Wo sie antwortet

| Kanal | So erreichen Gäste sie |
| --- | --- |
| **Website** | Ein Chat-Knopf auf Ihrer Website |
| **E-Mail** | Antworten auf E-Mails an die Adresse Ihres Ladens |
| **WhatsApp** | Die eigene WhatsApp-Nummer Ihres Ladens |

## Automatisch antworten oder nur vorschlagen

Für jeden Kanal wählen Sie:

- **Automatisch antworten**: Antworten gehen sofort raus. Unsichere Fälle kommen zu Ihnen.
- **Nur Entwürfe**: Jede Antwort wartet im [Posteingang](/de/ai-receptionist/inbox/) auf Ihr OK. Sie senden sie mit einem Tipp.

Beginnen Sie mit Entwürfen, wenn Sie zuerst sehen möchten, wie sie schreibt.

## Sie schreibt wie Ihre Rezeption

Die Antworten sind kurz und natürlich, wie bei einem Menschen, der eine Nachricht tippt. Keine Listen, kein Fettdruck. Auf WhatsApp kommen längere Antworten als zwei Nachrichten mit einer kurzen „schreibt…“-Pause. Die Persönlichkeit legen Sie unter [Persönlichkeit](/de/ai-receptionist/personality/) fest.

:::note
Fragt ein Gast nach, sagt die Rezeption, dass sie die KI-Assistentin des Ladens ist. Sie gibt sich nie als Mensch aus.
:::
