title: Auf WhatsApp testen
description: Die Rezeption mit Ihrer eigenen WhatsApp-Nummer ausprobieren, ohne zweites Handy.
sidebar:
  order: 3
---

Nachrichten, die Sie vom Handy des Ladens schicken, gelten als Nachrichten **vom Laden**. Die KI beachtet sie nicht. So mischt sie sich nie ein, wenn Sie oder Ihr Team Gästen schreiben.

Wenn Sie selbst testen möchten, beginnen Sie Ihre Nachricht mit **#test**:

1. Öffnen Sie auf dem Handy des Ladens WhatsApp und den Chat mit sich selbst (Ihre eigene Nummer).
2. Schreiben Sie zum Beispiel: `#test Habt ihr morgen um 15 Uhr Zeit?`
3. Die KI antwortet im selben Chat, als wären Sie ein Gast.

:::caution[Echte Gäste]
Solange WhatsApp auf **Automatisch antworten** steht, bekommen auch echte Gäste Antworten. Wenn Sie nur testen möchten, wählen Sie unter **Kanäle** die Einstellung **Nur Entwürfe**.
:::
