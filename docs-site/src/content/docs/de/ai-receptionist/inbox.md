Der Reiter **Posteingang** funktioniert wie ein Messenger: links alle Chats, rechts der geöffnete Chat. Auf dem Handy sehen Sie zuerst die Liste und dann den Chat.

## Einen Chat finden

- **Chats durchsuchen**: nach Name, Telefon, E-Mail oder Text.
- Filter: **Alle**, **Braucht Sie** und die Symbole für WhatsApp, E-Mail und Website.
- Ein kleines Zeichen am Profilbild zeigt den Kanal. Ein grüner Punkt bedeutet: ungelesen. **Braucht Sie** markiert Chats, die die KI an Sie übergeben hat oder in denen ein Entwurf auf Sie wartet.

## Antworten

Öffnen Sie einen Chat, schreiben Sie unten in das Feld und drücken Sie **Enter** (Shift + Enter für eine neue Zeile). Ihre Antwort geht über denselben Kanal raus: WhatsApp, E-Mail oder Website-Chat.

Wenn Sie selbst antworten, können Sie die KI für diesen einen Chat ausschalten (**Team antwortet hier**) und später wieder einschalten (**KI antwortet hier**).

## Entwürfe

Steht ein Kanal auf **Nur Entwürfe**, wartet die Antwort der KI im Chat als **Entwurf – noch nicht gesendet**. Tippen Sie auf **Diese Antwort senden**, ändern Sie sie vorher mit **Bearbeiten**, oder tippen Sie auf **Verwerfen**.

## Einen neuen Chat beginnen

Tippen Sie auf den Stift-Knopf neben der Suche. Wählen Sie **WhatsApp** oder **E-Mail**. Wählen Sie einen Gast aus oder geben Sie eine Nummer oder Adresse ein. Schreiben Sie Ihre Nachricht und senden Sie sie ab.

:::note
Für neue WhatsApp-Chats brauchen Sie die WhatsApp-Verbindung mit Ihrer eigenen Nummer (QR-Code). Für E-Mail muss Ihr Postfach verbunden sein.
:::
