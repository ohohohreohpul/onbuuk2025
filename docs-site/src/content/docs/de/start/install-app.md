---
title: Zenno wie eine App nutzen
description: Legen Sie Zenno auf den Startbildschirm Ihres Tablets oder Handys.
sidebar:
  order: 3
---

Zenno läuft im Browser. Sie können es auf den Startbildschirm legen. Dann öffnet es sich wie eine App, im Vollbild und direkt mit Ihrem Kalender.

- **iPad / iPhone (Safari):** Öffnen Sie Ihre Zenno-Adresse, tippen Sie auf **Teilen** und dann auf **Zum Home-Bildschirm**.
- **Android (Chrome):** Öffnen Sie Ihre Zenno-Adresse, tippen Sie auf das Menü **⋮** und dann auf **App installieren** oder **Zum Startbildschirm hinzufügen**.
- **Computer (Chrome oder Edge):** Klicken Sie auf das Installieren-Symbol rechts in der Adressleiste.

Zenno aktualisiert sich selbst. Gibt es eine neue Version, wird sie beim nächsten Öffnen geladen.
