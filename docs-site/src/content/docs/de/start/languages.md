**Ihre eigene Sprache in der App:** Tippen Sie unten im Menü auf **DE**, **EN** oder **ไทย**. Jede Person in Ihrem Team kann ihre eigene Sprache wählen.

**Die Sprache für Ihre Gäste** (Buchungsseite und E-Mails) stellen Sie einmal für den ganzen Laden ein: **Einstellungen → Shop-Profil → Sprache von Buchungsseite und E-Mails**.

Die KI-Rezeption antwortet immer in der Sprache des Gastes.
