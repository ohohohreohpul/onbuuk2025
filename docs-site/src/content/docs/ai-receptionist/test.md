Messages you send from the shop's own phone are treated as messages **from the shop**, so the AI ignores them. That way it never interrupts when you or your team write to guests.

To test it yourself, start your message with **#test**:

1. On the shop's phone, open WhatsApp and the chat **Message yourself** (your own number).
2. Write for example: `#test Do you have time tomorrow at 3 pm?`
3. The AI answers in the same chat, as if you were a guest.

:::caution[Real guests]
While WhatsApp is set to **answer automatically**, real guests get answers too. If you only want to test, choose **Write drafts only** in **Channels**.
:::
