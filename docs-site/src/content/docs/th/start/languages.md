**ภาษาของคุณเองในแอป:** แตะ **DE**, **EN** หรือ **ไทย** ที่ด้านล่างของเมนู ทุกคนในทีมเลือกภาษาของตัวเองได้

**ภาษาที่ลูกค้าเห็น** (หน้าจองและอีเมล) ตั้งครั้งเดียวสำหรับทั้งร้าน ที่ **การตั้งค่า → ข้อมูลร้าน → ภาษาของหน้าจองและอีเมล**

พนักงานต้อนรับ AI ตอบเป็นภาษาของลูกค้าเสมอ
