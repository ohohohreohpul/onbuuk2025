description: อะไรอยู่ตรงไหนในเมนู
sidebar:
  order: 2
---

| เมนู | ทำอะไรได้ที่นั่น |
| --- | --- |
| **POS** | ปฏิทินและตัวเลขของวันนี้ เพิ่มนัดหมาย ปิดเวลา ขายและใช้บัตรของขวัญ |
| **พนักงานต้อนรับ AI** | แชทจาก WhatsApp อีเมล และเว็บไซต์ของคุณ บุคลิกของพนักงานต้อนรับ และช่องทางต่างๆ |
| **การจอง** | การจองทั้งหมดเป็นรายการ พร้อมสิ่งที่คุณต้องทำ |
| **ลูกค้า** | ลูกค้าทุกคน พร้อมจำนวนครั้งที่มา ยอดใช้จ่าย การไม่มาตามนัด และโน้ต |
| **อีเมลการตลาด** | อีเมลโปรโมชันถึงลูกค้าเดือนละครั้ง |
| **บริการ** · **สินค้าเสริม** | บริการ ระยะเวลา ราคา และของเสริม |
| **พนักงานบริการ** | พนักงาน เวลาทำงาน วันลา และวันปิดร้าน |
| **ทีมและสิทธิ์การใช้งาน** | เชิญทีมของคุณ และกำหนดว่าใครเห็นอะไร |
| **การจองผ่าน AI** | ให้ ChatGPT, Siri และผู้ช่วย AI อื่นๆ จองคิวกับร้านคุณได้ |
| **ค่าธรรมเนียมไม่มาตามนัด** · **บัตรของขวัญ** · **ภาษีและรายงาน** | เรื่องเงิน: ค่าธรรมเนียม บัตรของขวัญและบัตรบริการ สมุดเงินสด และรายงาน |
| **การตั้งค่า** | ข้อมูลร้าน หน้าตาหน้าจอง อีเมล การชำระเงิน ใบแจ้งหนี้ การนำเข้าข้อมูล |

คุณจะเห็นเฉพาะเมนูที่บทบาทของคุณอนุญาต ที่ด้านล่างของเมนูมี: ภาษา (**DE · EN · ไทย**) **คู่มือการใช้งาน** **ขอความช่วยเหลือ** และ **ออกจากระบบ**
