---

Zenno ทำงานในเบราว์เซอร์ และคุณเพิ่มไว้ที่หน้าจอหลักได้ แล้วจะเปิดเหมือนแอป เต็มจอ และเข้าปฏิทินทันที

- **iPad / iPhone (Safari):** เปิดที่อยู่ Zenno ของคุณ แตะปุ่ม **แชร์** แล้วแตะ **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** เปิดที่อยู่ Zenno ของคุณ แตะเมนู **⋮** แล้วแตะ **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
- **คอมพิวเตอร์ (Chrome หรือ Edge):** คลิกไอคอนติดตั้งที่ด้านขวาสุดของแถบที่อยู่

Zenno อัปเดตเอง เมื่อมีเวอร์ชันใหม่ ระบบจะโหลดให้ในครั้งถัดไปที่คุณเปิด
