ทำขั้นตอนเหล่านี้เพียงครั้งเดียว แต่ละขั้นตอนใช้เวลาไม่กี่นาที

1. **ข้อมูลร้าน** ไปที่ **การตั้งค่า → ข้อมูลร้าน** กรอก **ชื่อธุรกิจ** **ประเภทธุรกิจ** **เบอร์โทรศัพท์** **ที่อยู่ธุรกิจ** และ **ลิงก์ถาวร (Permalink)** (ที่อยู่ของหน้าจองของคุณ) เลือก **ภาษาของหน้าจองและอีเมล** แล้วแตะ **บันทึกข้อมูลร้าน** หน้าจองจะเปิดใช้งานเมื่อกรอกข้อมูลร้านครบ
2. **บริการ** ไปที่ **บริการ** → **เพิ่มบริการ** เพิ่มแต่ละบริการพร้อม **ระยะเวลาและราคา** ดูที่ [บริการ](/th/settings/services/)
3. **พนักงานบริการ** ไปที่ **พนักงานบริการ** → **เพิ่มพนักงานบริการ** ติ๊ก **บริการที่ให้** และตั้ง **เวลาทำงาน** ดูที่ [พนักงานบริการ](/th/settings/specialists/)
4. **อีเมล** ไปที่ **การตั้งค่า → อีเมล** แล้วตั้งค่าผู้ส่ง เพื่อให้ลูกค้าได้รับอีเมลยืนยันและแจ้งเตือน ดูที่ [อีเมล](/th/settings/emails/)
5. **การชำระเงิน (ไม่บังคับ)** ไปที่ **การตั้งค่า → การชำระเงิน** เพื่อรับชำระด้วยบัตรหรือ PayPal ออนไลน์ หรือ "ชำระที่ร้าน" ดูที่ [การชำระเงิน](/th/money/payments/)
6. **แชร์หน้าจองของคุณ** คัดลอกลิงก์จาก **ข้อมูลร้าน** (**คัดลอก**) แล้วนำไปใส่ในเว็บไซต์ Instagram และโปรไฟล์ Google ของคุณ

:::tip[ย้ายมาจากระบบจองอื่น?]
ที่ **การตั้งค่า → นำเข้า** คุณนำเข้าลูกค้า นัดหมาย และเวลาที่ปิดไว้จาก EasyWeek, Shore, Treatwell และระบบอื่นๆ ได้ (ไฟล์ CSV)
:::
