## เพิ่มบริการ

1. เปิด **บริการ** → **เพิ่มบริการ**
2. กรอก **ชื่อบริการ** **รายละเอียด** และ **หมวดหมู่** (หรือ **+ สร้างหมวดหมู่ใหม่**)
3. ที่ **ระยะเวลาและราคา** แตะ **เพิ่มระยะเวลา** สำหรับแต่ละความยาว เช่น 60 นาที · 70 € และ 90 นาที · 95 €
4. ไม่บังคับ:
   - **เปิดให้จองคู่**: ลูกค้าจองสำหรับสองคนได้
   - **ซ่อนจากหน้าจอง**: คุณยังจองบริการนี้ในปฏิทินได้ และบัตรของขวัญยังใช้ได้
   - **เวลาเผื่อก่อน / หลัง (นาที)**: เวลาสำหรับเตรียมตัวหรือเก็บของ
   - **ค่าธรรมเนียมไม่มาตามนัด** **ค่ายกเลิกล่าช้า** **ยกเลิกล่วงหน้า (ชั่วโมง)**
5. แตะ **สร้างบริการ**

มีบริการเยอะ? แตะ **นำเข้า** ดาวน์โหลดเทมเพลต กรอกข้อมูล แล้วอัปโหลด

## สินค้าเสริม

ที่ **สินค้าเสริม** → **เพิ่มสินค้า** คุณเสนอของเสริมที่ลูกค้าเพิ่มในการจองได้ เช่น หินร้อน หรือน้ำมันหอมระเหย: ชื่อ ราคา รูปภาพ และใช้ได้กับบริการไหนบ้าง
