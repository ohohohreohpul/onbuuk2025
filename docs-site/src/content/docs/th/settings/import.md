title: ย้ายมาจากระบบอื่น
description: นำเข้าลูกค้า นัดหมาย และเวลาที่ปิดไว้จาก EasyWeek, Shore, Treatwell และระบบอื่นๆ
sidebar:
  order: 6
---

1. ส่งออกข้อมูลจากระบบเดิมของคุณเป็นไฟล์ CSV
2. ใน Zenno ไปที่ **การตั้งค่า → นำเข้า** → **นำเข้าจากระบบอื่น**
3. เลือกสิ่งที่ต้องการนำเข้า: **ลูกค้า** **นัดหมาย** หรือ **ช่วงเวลาปิดรับจอง** แล้วอัปโหลดไฟล์
4. ตรวจดูตัวอย่าง แล้วนำเข้า

นัดหมายที่นำเข้าจะไม่ส่งอีเมลยืนยัน แต่ลูกค้ายังได้รับอีเมลแจ้งเตือนล่วงหน้าหนึ่งวันตามปกติ

บริการนำเข้าได้ที่ **บริการ** → **นำเข้า** ส่วนบัตรของขวัญนำเข้าได้ที่ **บัตรของขวัญ → บัตรของขวัญ** → **นำเข้า CSV**
