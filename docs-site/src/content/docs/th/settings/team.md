1. เปิด **ทีมและสิทธิ์การใช้งาน** → **เชิญสมาชิกทีม**
2. กรอก **ชื่อ-นามสกุล** และ **อีเมล** แล้วเลือก **บทบาทหลัก**
3. แตะ **ส่งคำเชิญ** คนนั้นจะได้รับอีเมลเพื่อสร้างบัญชีเข้าสู่ระบบ

## บทบาท

| บทบาท | ทำอะไรได้ |
| --- | --- |
| **เจ้าของร้าน** | ทุกอย่าง รวมถึงการชำระเงิน |
| **ผู้จัดการ** | การจองและปฏิทินทั้งหมด ลูกค้า การชำระเงิน บัตรของขวัญ บริการ พนักงาน รายงาน |
| **พนักงานต้อนรับ** | สร้าง แก้ไข และยกเลิกการจองทั้งหมด ดูปฏิทินทั้งหมด ลูกค้าและโน้ต รับชำระเงิน |
| **แคชเชียร์** | ดูการจองและลูกค้า รับชำระเงิน ดูบัตรของขวัญ |
| **พนักงาน** | การจอง ปฏิทิน และเวลาว่างของตัวเอง ดูลูกค้าและบริการ |

ให้บทบาทเพิ่มกับใครได้ด้วย **+ เพิ่มบทบาท** **ปิดการใช้งาน** จะยกเลิกสิทธิ์เข้าใช้ โดยไม่ลบข้อมูลของคนนั้น คำเชิญที่ยังไม่ตอบรับส่งอีกครั้งหรือยกเลิกได้ที่ **คำเชิญ**
