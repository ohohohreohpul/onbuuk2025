ในแอป แตะ **ขอความช่วยเหลือ** ที่ด้านล่างของเมนู แล้วแตะ **เขียนอีเมล** แอปอีเมลจะเปิดขึ้นพร้อมกรอกข้อมูลบัญชีของคุณไว้ให้แล้ว เราจึงช่วยได้เร็วขึ้น

หรือเขียนถึง **support@zennohq.com** โดยตรง

กรุณาบอกเรา:

1. คุณต้องการทำอะไร
2. แต่เกิดอะไรขึ้นแทน
3. ภาพหน้าจอ ถ้าทำได้

ทีมงาน Zenno ตัวจริงจะเป็นคนตอบคุณ
