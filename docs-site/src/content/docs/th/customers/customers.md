ระบบเพิ่มลูกค้าให้อัตโนมัติเมื่อมีการจอง เปิด **ลูกค้า** เพื่อค้นหาด้วยชื่อ อีเมล หรือเบอร์โทร

รายการจะแสดง **จำนวนครั้ง** **ไม่มาตามนัด** **ยอดใช้จ่ายรวม** และวันที่มาครั้งแรกและครั้งล่าสุด ลูกค้าที่มาบ่อยจะมีป้าย **ลูกค้าประจำ**

แตะลูกค้าเพื่อดู **ข้อมูลลูกค้า** **การจอง** **ค่าธรรมเนียม** และ **บันทึก** บันทึกเห็นเฉพาะทีมของคุณ

ย้ายมาจากระบบอื่น? นำเข้าลูกค้าได้ที่ **การตั้งค่า → นำเข้า**
