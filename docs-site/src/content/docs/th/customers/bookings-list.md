เปิด **การจอง** กรองด้วย **ต้องดำเนินการ** **กำลังจะมาถึง** **ที่ผ่านมา** **ยกเลิกและไม่มาตามนัด** หรือ **ทั้งหมด** หรือค้นหาด้วยชื่อหรืออีเมล

คอลัมน์ **ขั้นตอนถัดไป** บอกว่ายังเหลืออะไรต้องทำ: ยืนยัน "ลูกค้ามาหรือไม่?" การชำระเงิน แตะ **แก้ไข** เพื่อทำต่อ ขั้นตอนเหมือนกับในปฏิทิน ดูที่ [ยืนยัน รับชำระเงิน เลื่อน หรือยกเลิก](/th/pos/manage-booking/)

นัดหมายใหม่เพิ่มได้ที่ [POS](/th/pos/create-booking/)
