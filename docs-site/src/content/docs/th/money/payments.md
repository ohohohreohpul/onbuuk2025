เฉพาะเจ้าของร้านเท่านั้นที่เปลี่ยนการตั้งค่าการชำระเงินได้ ไปที่ **การตั้งค่า → การชำระเงิน**

- **ชำระด้วยบัตร (Stripe):** แตะ **เชื่อมต่อ Stripe** เลือกประเทศ แล้วตั้งค่ากับ Stripe ให้เสร็จ เมื่อขึ้น **รับชำระเงินได้** และ **รับเงินโอนได้** แล้ว ให้เปิด **รับชำระด้วยบัตรออนไลน์**
- **ชำระที่ร้าน:** เปิด **แสดงตัวเลือก “ชำระที่ร้าน” ตอนชำระเงิน** สำหรับบริการที่มีค่าธรรมเนียมไม่มาตามนัด ลูกค้าต้องให้ข้อมูลบัตรไว้เป็นหลักประกัน แต่ยังไม่ถูกตัดเงินตอนนี้
- **PayPal:** เปิด **รับชำระผ่าน PayPal** แล้วกรอก client ID และ secret ของ PayPal

การชำระเงินที่เคาน์เตอร์บันทึกไว้ในการจอง ดูที่ [ยืนยัน รับชำระเงิน เลื่อน หรือยกเลิก](/th/pos/manage-booking/)
