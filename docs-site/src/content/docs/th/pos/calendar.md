**POS** เป็นเมนูแรก เปิดแล้วจะเห็นปฏิทิน และด้านล่างคือตัวเลขของวันนี้ (ถ้าคุณมีสิทธิ์ดูรายงาน) ส่วนใหญ่ของวัน คุณใช้แค่หน้านี้หน้าเดียว

## วัน สัปดาห์ เดือน

ด้านบนสลับได้ระหว่าง **วัน** **สัปดาห์** และ **เดือน** ใช้ลูกศรเพื่อย้อนกลับหรือไปข้างหน้า และแตะ **วันนี้** เพื่อกลับมาวันปัจจุบัน

- **วัน** แสดงหนึ่งคอลัมน์ต่อพนักงานหนึ่งคน เหมาะที่สุดสำหรับใช้ที่เคาน์เตอร์
- **สัปดาห์** แสดงทั้งสัปดาห์ พนักงานทุกคนรวมกัน
- **เดือน** ให้ภาพรวม แตะวันใดก็ได้เพื่อเปิดดู

## สีต่างๆ หมายถึงอะไร

พนักงานแต่ละคนมีสีของตัวเอง การ์ดการจองจะแสดงจุดสีเล็กๆ เวลาเริ่ม ชื่อลูกค้า และบริการ

| คุณเห็น | หมายความว่า |
| --- | --- |
| การ์ดสีของพนักงาน | การจองที่ยืนยันแล้ว |
| การ์ดสีเหลืองขอบเส้นประ "รอยืนยัน" | การจองกำลังรอให้คุณยืนยัน |
| เครื่องหมายถูกสีเขียวเล็กๆ | การจองชำระเงินแล้ว |
| ชื่อจางและถูกขีดฆ่า "ไม่มา" | ลูกค้าไม่มาตามนัด (no-show) |
| ช่องลายทาง | เวลาที่ปิดไว้ พร้อมหมายเหตุ |
| เส้นสีแดง | เวลาปัจจุบัน |

## ทำสิ่งต่างๆ

- **แตะเวลาที่ว่าง** หน้าต่างเล็กๆ จะถามว่า *ต้องการทำอะไร?*: **เพิ่มนัดหมาย** หรือ **ปิดเวลา** เมื่อเลื่อนเมาส์บนปฏิทิน จะมี "+ 14:30" เล็กๆ บอกว่าจะเริ่มที่เวลาไหน
- **แตะการจอง** เพื่อยืนยัน บันทึกว่าลูกค้ามาหรือไม่ รับชำระเงิน เลื่อนหรือยกเลิก หรือเขียนโน้ตสำหรับทีม
- **แตะเวลาที่ปิดไว้** เพื่อแก้ไข ยกเลิก หรือเปลี่ยนเป็นนัดหมายจริง
- ปุ่ม **ขายบัตรของขวัญ** และ **ใช้บัตรของขวัญ** อยู่ด้านบนของปฏิทิน
- **แสดงพนักงาน** ให้คุณเลือกว่าจะดูคอลัมน์ของใคร

:::tip
ถ้าใช้แท็บเล็ตที่เคาน์เตอร์ ให้เปิดปฏิทินไว้ที่ **วัน** ทุกอย่างที่ต้องใช้อยู่ห่างแค่แตะเดียว
:::
