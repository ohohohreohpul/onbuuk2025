---
title: เพิ่มนัดหมาย
description: ลงการจองให้ลูกค้าที่โทรมาหรือเดินเข้าร้าน
sidebar:
  order: 2
---

1. ใน **POS** แตะเวลาว่างที่ต้องการให้นัดหมายเริ่ม (ในมุมมองวัน: แตะในคอลัมน์ของพนักงาน)
2. เลือก **เพิ่มนัดหมาย** หน้าต่าง **เพิ่มนัดหมาย** จะเปิดขึ้น
3. เลือก **บริการ** และ **ระยะเวลา** ราคาจะแสดงข้างแต่ละระยะเวลา
4. ตรวจดู **พนักงานบริการ** และ **วันและเวลา** Zenno จะแสดง **เวลาว่าง** ให้แตะเลือกหนึ่งเวลา
5. ที่ **ลูกค้า** ค้นหาด้วยชื่อ เบอร์โทร หรืออีเมล ลูกค้าใหม่หรือเปล่า? แตะ **ลูกค้าใหม่** แล้วกรอก **ชื่อ** **โทรศัพท์** และ **อีเมล** ถ้ามี (ระบบจะส่งการยืนยันไปที่อีเมลนี้)
6. ถ้าจำเป็น เขียน **โน้ตสำหรับทีม** เช่น "กดแรง แพ้สาร" เห็นเฉพาะทีมของคุณ
7. แตะ **เพิ่มนัดหมาย**

นัดหมายจะขึ้นในปฏิทินทันที

:::note[ค้นหาด้วยเบอร์โทร]
พิมพ์เบอร์โทรแบบไหนก็ได้ มีช่องว่าง ขึ้นต้นด้วย +49 หรือ 0 ก็ได้ Zenno จะหาลูกค้าจากตัวเลขท้ายๆ
:::

:::tip[คนที่โทรมาขอคิดดูก่อน]
จองเวลาไว้โดยยังไม่ต้องสร้างการจอง: [ปิดเวลา](/th/pos/block-time/) พร้อมเขียนหมายเหตุ แล้วค่อยเปลี่ยนเป็นนัดหมายจริงด้วยการแตะครั้งเดียว
:::
